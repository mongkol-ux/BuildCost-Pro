# BuildCost Pro API — V1.1 Foundation

The API remains the authoritative service boundary for V1.1 application development.

## Responsibilities

- Authentication and authorization
- Business validation
- Domain/business rules
- Persistence and data access
- Stable request/response contracts
- Production security and operational controls

## Client contract

The web application communicates with this service over HTTPS using documented API endpoints. No client-side code may connect directly to the production database.

## V1.1 integration sequence

1. Confirm authentication contract.
2. Confirm project contract.
3. Confirm cost/estimate contract.
4. Add typed/client adapters.
5. Add integration tests.

Feature implementation begins in STEP 27.
