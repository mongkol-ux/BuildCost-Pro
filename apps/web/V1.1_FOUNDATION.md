# BuildCost Pro Web — V1.1 Foundation

This directory is the application boundary for the V1.1 web client.

## Foundation responsibilities

- UI and navigation
- Authentication/session presentation
- API client integration
- Loading, empty and error states
- Project and cost workflow screens

## Boundary rules

The web client must not access the production database directly. Runtime configuration and secrets must come from the deployment environment, never committed source.

## V1.1 first slice

Login -> Application Shell -> Dashboard -> Projects.

Business workflows are implemented in STEP 27 and later after the foundation gate is closed.
